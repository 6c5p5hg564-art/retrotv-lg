# RETROTV ULTRA — LG webOS / GitHub Pages

Interface de bibliothèque premium conçue pour un navigateur TV LG, sans serveur ni installation native.

## Installation depuis iPhone
1. Décompresser l'archive dans Fichiers.
2. Dans le dépôt GitHub Pages existant `retrotv-lg`, remplacer **ensemble** les fichiers `index.html`, `style.css` et `app.js` à la racine.
3. Attendre le déploiement GitHub Pages et recharger la page sur le LG (au besoin vider le cache).

## Images
Les visuels sont chargés en ligne depuis les images de pages Wikipédia (API pageimages) et les images publiques de la boutique Steam. Il s'agit de visuels réels associés aux jeux, non de reproductions générées. Certains peuvent être des logos, captures ou visuels différents de la jaquette. Leur chargement dépend du réseau, des restrictions de ces services et des capacités du navigateur LG. En cas d'échec, une carte de remplacement s'affiche. Aucune image tierce n'est redistribuée dans l'archive.

## Limites
Ceci est une maquette interactive de bibliothèque, **pas un émulateur**. Aucun jeu, ROM, BIOS ni logiciel d'émulation n'est fourni. Les favoris sont stockés localement quand le navigateur le permet. Les visuels et les marques appartiennent à leurs ayants droit. Le navigateur webOS du LG 55UL3E-B n'a pas été testé directement.
